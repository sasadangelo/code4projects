# Glossary

**Attribute**
: Extra information added to the opening tag of an HTML element, written as a
  name and a value, such as `href="index.html"` or `alt="Logo"`.

**Box Model**
: The CSS model that describes every element as a rectangular box made of four
  layers: content, padding, border, and margin.

**Breakpoint**
: The screen width at which a media query changes the layout of a page, for
  example switching from a horizontal menu to a hamburger menu.

**Cascade**
: The set of rules CSS uses to decide which declaration wins when several rules
  target the same element. It considers origin, specificity, and source order.

**CSS (Cascading Style Sheets)**
: The language that describes how HTML elements are displayed: colours, fonts,
  spacing, layout, and animations.

**CSS Grid**
: A two-dimensional CSS layout system that arranges elements in rows and columns.
  Ideal for galleries and page-level layouts.

**Declaration**
: A single `property: value` pair inside a CSS rule, such as `color: blue;`.

**DOCTYPE**
: The first line of an HTML document (`<!DOCTYPE html>`). It tells the browser
  which version of HTML the page uses, so it renders in standards mode.

**Element**
: The basic building block of an HTML page, made of an opening tag, content, and
  a closing tag, such as `<p>Hello</p>`.

**Flexbox**
: A one-dimensional CSS layout system that distributes space among items in a
  row or a column. Commonly used for navigation bars and headers.

**Font Awesome**
: A popular icon library that provides scalable vector icons (such as social
  media logos) through CSS classes.

**Form**
: An HTML element (`<form>`) that collects user input through controls such as
  `<input>`, `<textarea>`, and `<button>`.

**Hamburger Menu**
: The three-line icon that replaces a horizontal navigation bar on small screens
  and opens the menu when tapped.

**Hero Image**
: A large, prominent banner image at the top of a home page, usually combined
  with a short welcome message.

**HTML (HyperText Markup Language)**
: The standard markup language used to describe the structure and content of
  web pages.

**Hyperlink**
: A clickable reference to another page or location, created with the `<a>` tag
  and its `href` attribute.

**Inheritance**
: The CSS mechanism by which some properties, such as `color` and `font-family`,
  are passed from a parent element to its children.

**Lightbox**
: A UI pattern that shows an enlarged image in an overlay on top of the page,
  typically closed by clicking outside it.

**Lorem Ipsum**
: Placeholder text used in design and development to fill a layout before the
  real content is available.

**Media Query**
: A CSS rule (`@media`) that applies styles only when a condition is true, such
  as a maximum screen width. The foundation of responsive design.

**Pseudo-element**
: A CSS keyword such as `::before` or `::after` that styles a specific part of an
  element, or inserts decorative content, without extra HTML.

**Responsive Design**
: An approach to web design that makes pages adapt to any screen size, from
  phones to large desktop monitors.

**Selector**
: The part of a CSS rule that determines which HTML elements the rule applies to:
  element, class, ID, attribute, and more.

**Semantic HTML**
: The use of HTML tags that describe the meaning of their content, such as
  `<header>`, `<nav>`, `<main>`, and `<footer>`, instead of generic `<div>` tags.

**Specificity**
: The weight CSS assigns to a selector. When two rules conflict, the one with the
  higher specificity wins: ID selectors beat class selectors, which beat element
  selectors.

**Tag**
: A keyword enclosed in angle brackets, such as `<p>` or `</p>`, that marks the
  beginning or the end of an HTML element.

**Viewport**
: The visible area of a web page in the browser window. The viewport meta tag
  tells mobile browsers to match the page width to the device width.
