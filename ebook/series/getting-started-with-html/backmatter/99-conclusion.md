# What's Next?

You have reached the end of this book. If you have worked through each chapter,
you now know how to:

- Write a well-structured HTML document with headings, paragraphs, links, lists,
  and images
- Style a page with CSS selectors, the box model, typography, and colours
- Organise a site with semantic tags such as `<header>`, `<nav>`, `<main>`, and
  `<footer>`
- Build a navigation bar, a hero section, and a consistent header and footer
- Make a site responsive with the viewport meta tag, media queries, and a
  hamburger menu
- Collect user input with HTML forms
- Lay out a photo gallery with CSS Grid and add your first lines of JavaScript

That is a complete, practical foundation. You have gone from a blank text file to
a real, multi-page website that works on every screen.

## Where to Go From Here

### JavaScript

The lightbox in the last chapter was only a taste. JavaScript turns static pages
into interactive applications: form validation, dynamic content, calls to web
APIs. It is the natural third language of the web after HTML and CSS.

### Modern CSS

CSS keeps evolving. Custom properties (CSS variables), container queries, the
`:has()` selector, and native nesting let you write cleaner, more maintainable
stylesheets with less code.

### Accessibility

A website is only as good as the number of people who can use it. Learning ARIA
attributes, keyboard navigation, and colour-contrast guidelines makes your pages
usable by everyone, including people who rely on screen readers.

### Static Site Generators and Hosting

Writing every page by hand does not scale. Tools such as Jekyll or Hugo generate a
whole site from templates and Markdown files, and services such as GitHub Pages
host it for free. This very blog, Code4Projects, is built that way.
