# Preface

Every web page you have ever visited is built on two languages: HTML, which gives
a page its structure, and CSS, which gives it its look. Frameworks, page builders,
and JavaScript libraries come and go, but underneath all of them there is always
plain HTML and CSS.

Most beginner tutorials stop at isolated snippets: a heading here, a coloured box
there. You learn the tags but never see how they come together into a real site.

This book takes a different path. It follows a single project, **html-hero**, from
a blank text file to a complete, responsive, multi-page website. Every chapter
introduces a handful of concepts and immediately applies them to that project, so
by the last page you will have built a real site with a header, a navigation bar,
a home page with a hero image, a contact form, and an interactive photo gallery.

## Who This Book Is For

This book is for readers who:

- Have never written a line of HTML or CSS and want to start from zero
- Have copied snippets from the web but never understood how a page is structured
- Want to build their own personal website without relying on a page builder
- Want a single, coherent reference instead of scattered blog posts

No prior programming knowledge is assumed. A text editor and a web browser are all
you need.

## How to Read the Code

All the source code is organised in lessons. Each lesson has its own folder, so you
can open the result of every step in your browser and compare it with your own
work. When a chapter says "download the file of lesson 5", you will find it in the
corresponding `lesson-05` folder of the repository.
