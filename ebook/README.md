# eBook Build System

This folder contains everything needed to generate PDF ebooks from the blog post series.

## Structure

```
ebook/
├── README.md                  ← this file
├── build-ebook.sh             ← build script (shared by all series)
├── templates/
│   └── ebook.latex            ← LaTeX template (shared by all series)
└── series/
    ├── getting-started-with-docker/
    │   ├── metadata.yml       ← title, author, cover, dedication, post_series_id
    │   ├── frontmatter/
    │   │   ├── cover.png
    │   │   └── 01-preface.md
    │   └── backmatter/
    │       ├── 98-glossary.md
    │       └── 99-conclusion.md
    └── getting-started-with-html/   ← same structure (+ cover.svg, source of cover.png)
```

## What is shared and what is per series

Shared by every book (`build-ebook.sh` + `templates/ebook.latex`):

- **Cover page** — rendered from `cover-image` in `metadata.yml`
  (a text title page is used when it is missing)
- **Dedication page** — one centred line per item of `dedication` in `metadata.yml`
  (Markdown allowed: `*italic*`, `` `code` ``)
- **Table of contents** — generated by pandoc from the chapter headings
- **Chapters** — one per post, titled with the post `title`
- **Preface chapter list** — a `<!-- chapters -->` line in any frontmatter file is
  replaced with a numbered list of the posts (title + `excerpt`)
- Page layout, fonts, headers/footers, code highlighting

Written per series: `metadata.yml`, the cover image, the preface, the glossary,
and the conclusion.

## How to build an ebook

```bash
# Build a specific series
./build-ebook.sh getting-started-with-docker

# The output PDF will be in:
# ebook/series/getting-started-with-docker/build/getting-started-with-docker.pdf
```

## How to add a new series

1. Create the folder: `ebook/series/<post_series_id>/`
2. Copy the structure from an existing series
3. Edit `metadata.yml` with the book details (title, cover-image, dedication, post_series_id)
4. Write the preface (with a `<!-- chapters -->` line), glossary, and conclusion
5. Run `./build-ebook.sh <post_series_id>`

The script automatically picks up all `_posts/*.md` files whose frontmatter
contains `post_series_id: <series>`, strips Jekyll frontmatter, and assembles
them in date order between the front and back matter. Code blocks are kept
verbatim; SVG/WebP images are replaced with a PNG next to the original when one
exists, otherwise converted on the fly (`rsvg-convert`, `dwebp`, or ImageMagick).

## Prerequisites

- `pandoc` >= 3.0  (`brew install pandoc`)
- `xelatex`  (`brew install --cask mactex-no-gui`)
- DejaVu fonts or any system font you configure in `metadata.yml`
