# Resources for Developers

![Resources for Developers]({{ site.baseurl }}/wp-content/uploads/2018/06/Resources-Developers.jpg){:width="218" height="200" .responsive_img}

In this page, I collect the websites, free ebooks, books, and other resources I find most helpful as a software developer. These are the sources I read regularly and the ones I go back to when I write the articles on this blog. If you think a resource deserves to be listed here, feel free to contact me.

## Python

[Real Python](https://realpython.com/) — in-depth tutorials on almost every Python topic, from the basics to async, testing, and packaging.

[Python Documentation](https://docs.python.org/3/) — the official docs. The tutorial and the standard library reference are better than most books.

[Python Enhancement Proposals (PEPs)](https://peps.python.org/) — where you understand *why* the language works the way it does (PEP 8, PEP 484, PEP 621, …).

[FastAPI](https://fastapi.tiangolo.com/) — the documentation of the framework I use for REST APIs, and one of the best-written docs around.

[Pydantic](https://docs.pydantic.dev/) — data validation and settings management with type hints.

[SQLAlchemy](https://docs.sqlalchemy.org/) — the reference for the ORM and the database layer.

[Hynek Schlawack](https://hynek.me/articles/) — thoughtful articles on Python packaging, testing, and project structure.

[Talk Python To Me](https://talkpython.fm/) — a podcast with the people who build the Python ecosystem.

## Software Architecture

[Martin Fowler](https://martinfowler.com/) — the classic reference on architecture, refactoring, microservices, and enterprise patterns.

[Microservices.io](https://microservices.io/) — Chris Richardson's catalogue of microservice patterns.

[The C4 Model](https://c4model.com/) — a simple way to draw architecture diagrams at different levels of detail.

[Architecture Decision Records](https://adr.github.io/) — how to document architectural decisions so you still remember them in a year.

[The Twelve-Factor App](https://12factor.net/) — twelve principles for building cloud-ready applications.

[Refactoring.Guru](https://refactoring.guru/design-patterns) — design patterns and refactoring explained with clear diagrams and code examples.

[System Design Primer](https://github.com/donnemartin/system-design-primer) — a free, complete guide to designing large-scale systems.

[ByteByteGo](https://blog.bytebytego.com/) — system design explained with excellent diagrams.

[High Scalability](http://highscalability.com/) — real-world architectures of large-scale systems.

[InfoQ Architecture & Design](https://www.infoq.com/architecture-design/) — articles and talks from practitioners on architecture.

## Containers and Cloud Native

[Docker Documentation](https://docs.docker.com/) — the official guides and reference for Docker and Docker Compose.

[Kubernetes Documentation](https://kubernetes.io/docs/home/) — concepts, tutorials, and reference for Kubernetes.

[CNCF Blog](https://www.cncf.io/blog/) — news and articles from the Cloud Native Computing Foundation.

## AI and LLMs

[Simon Willison](https://simonwillison.net/) — the best day-to-day source on what you can actually build with LLMs.

[Lilian Weng](https://lilianweng.github.io/) — deep, well-researched articles on LLMs, agents, and prompt engineering.

[Hugging Face Blog](https://huggingface.co/blog) — open models, datasets, and practical guides.

[Anthropic Engineering](https://www.anthropic.com/engineering) — articles on building agents and tools with LLMs.

[LangChain](https://python.langchain.com/) — the documentation of the framework I use in the LLM chatbot series.

## Free Books

[Free Programming Books](https://github.com/EbookFoundation/free-programming-books) — thousands of free books on every language and topic, maintained by the community.

[The Architecture of Open Source Applications](https://aosabook.org/) — the authors of well-known open source projects explain how they are designed.

[Pro Git](https://git-scm.com/book) — the complete book on Git, free to read online.

## Blogs I Follow

[The Pragmatic Engineer](https://newsletter.pragmaticengineer.com/) — how software engineering really works inside tech companies.

[Simple Programmer](https://simpleprogrammer.com/) — career and soft skills for software developers.

[Tania Rascia](https://www.taniarascia.com/) — clear tutorials on web development and JavaScript.

[Pawel Grzybek](https://pawelgrzybek.com/) — front-end development, CSS, and JavaScript.

[Code4Startup](https://code4startup.com/) — learn programming by building real startup clones.

[ITNext](https://itnext.io/) — a Medium publication on cloud, Kubernetes, and DevOps.

## Resources for Game Programming

Software programming includes a wide range of topics that it is impossible to cover even in 30 years of experience. However, I consider game programming the funniest topic that a software developer can work on. Moreover, it is also a challenging task because games are very different from normal applications. They require dedicated skills that cover a wide range of topics like animation, programming, graphics, AI, physics, performance, and much more.

In this section, I collect the most important web resources for game programming.

[LibGdx](https://libgdx.com/)

[Game Programming Patterns](http://gameprogrammingpatterns.com/)

[Code in Complete](https://codeincomplete.com/)

[Programming Guide for Video-gamers](http://ithare.com/programming-guide-for-video-gamers/) (Thanks to Dylan for reporting)
